❤️ عشق واقعی یا فریب؟

درباره پروژه

عشق واقعی یا فریب یک بازی آموزشی و تعاملی درباره روابط انسانی، اعتماد، صداقت و تصمیم‌گیری است.

امکانات بازی

- شخصیت‌های مختلف با رفتارهای متفاوت
- گفت‌وگوهای تعاملی
- مراحل مختلف داستان
- سیستم امتیاز اعتماد
- پشتیبانی از زبان فارسی و انگلیسی
- تحلیل انتخاب‌های بازیکن در پایان بازی
- ارائه درس‌های آموزشی درباره روابط سالم

تکنالوژی‌های استفاده‌شده

- HTML برای ساختار صفحه
- CSS برای طراحی و زیباسازی
- JavaScript برای منطق و عملکرد بازی

هدف پروژه

هدف این پروژه کمک به بازیکنان برای شناخت روابط سالم، تشخیص رفتارهای مناسب و تصمیم‌گیری آگاهانه است.

سازنده
